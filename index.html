Задача 1 Модель в виде выражения

Пример:

Серёжа, Андрей и Денис принесли на выставку 120 почтовых марок. Серёжа принёс 25 марок, а Андрей — в 2 раза больше, чем Серёжа. Сколько марок принёс на выставку Денис?

Всего мальчики принесли 120 марок.

Серёжа принёс 25 марок, а Андрей — в 2 раза больше, то есть 25 · 2 марок.

Тогда Денис принёс 120 – (25 + 25 · 2) марок.

Найдём значение выражения:

25 · 2 = 50 25 + 50 = 75 120 – 75 = 45

Проверка: 25 + 50 + 45 = 120 — верно.

Математическая модель:
120 – (25 + 25 · 2)
Ответ:

Денис принёс на выставку 45 марок.

Задача для самостоятельного решения 1.1. В школьной библиотеке всего 340 книг. Из них 120 книг о приключениях, книг о животных — на 50 меньше, чем о приключениях, а остальные книги — о космосе. Сколько книг о космосе в библиотеке?

Показать решение и ответ

Книг о животных: 120 – 50 = 70.

Книги о приключениях и о животных вместе: 120 + 70 = 190.

Книг о космосе:

340 – 190 = 150

Проверка: 120 + 70 + 150 = 340 — верно.

Математическая модель:
340 – (120 + (120 – 50))
Ответ:

В библиотеке 150 книг о космосе.

x + 3x = 60

В соревнованиях участвовало 15 девочек и 45 мальчиков.

x + 2x + 3x = 96

В первой корзине 32 яблока, во второй — 16, в третьей — 48.

Задача для самостоятельного решения 2.2. В трёх альбомах 112 марок. В первом альбоме марок в 2 раза меньше, чем во втором, а в третьем — на 12 марок больше, чем во втором. Сколько марок в каждом альбоме?

Показать решение и ответ

Пусть в первом альбоме x марок. Тогда во втором — 2x, а в третьем — 2x + 12.

Всего марок x + 2x + (2x + 12), по условию — 112.

Решаем уравнение:

x + 2x + 2x + 12 = 112 5x + 12 = 112 5x = 112 – 12 5x = 100 x = 20

Значит, в первом альбоме 20, во втором — 40, в третьем — 52.

Проверка: 20 + 40 + 52 = 112 — верно.

Математическая модель:
x + 2x + (2x + 12) = 112
Ответ:

В первом альбоме 20 марок, во втором — 40, в третьем — 52.

Задача 3 Геометрическая модель

Пример:

Одна сторона прямоугольного участка земли на 3 м больше другой его стороны. Площадь участка равна 70 м². Найдите размеры этого участка.

Длина Ширина Площадь
(x + 3) м x м x(x + 3) м², или 70 м²

Пусть ширина участка равна x м. Тогда длина — (x + 3) м, а площадь — x(x + 3) м². По условию площадь равна 70 м², значит:

x(x + 3) = 70

Будем подставлять вместо x разные числа:

при x = 4: 4 · (4 + 3) = 28 — мало;

при x = 6: 6 · (6 + 3) = 54 — мало;

при x = 7: 7 · (7 + 3) = 70 — подходит!

Значит, x = 7. Тогда ширина 7 м, а длина 7 + 3 = 10 м.

Но нужно проверить, нет ли других решений. Если x > 7, то x + 3 > 10, и произведение будет больше 70. Если x < 7, то произведение будет меньше 70. Значит, x = 7 — единственное решение.

Ответ: стороны участка 7 м и 10 м.

Математическая модель:
x (x + 3) = 70
Ответ:

Стороны участка равны 7 м и 10 м.

Задача 4 Модель с двумя переменными

Пример:

На экскурсию едут 252 ученика. Заказали несколько одинаковых автобусов. Если заказать автобусы, вмещающие на 6 человек больше, то потребуется на 1 автобус меньше. Сколько больших автобусов надо заказать?

Пусть больших автобусов x. Тогда маленьких — x + 1, а число детей в каждом — 252 : x и 252 : (x + 1).

Количество детей
в одном автобусе		 Количество
автобусов		 Общее
количество детей
Большие
автобусы		 252 : x x 252
Маленькие
автобусы		 252 : (x + 1) x + 1 252

В большой автобус входит на 6 детей больше, значит:

252 : x – 252 : (x + 1) = 6

Подбираем x:

при x = 1: 252 : 1 – 252 : 2 = 252 – 126 = 126 — много;

при x = 2: 126 – 84 = 42 — много;

при x = 3: 84 – 63 = 21 — много;

при x = 6: 252 : 6 – 252 : 7 = 42 – 36 = 6 — подходит.

При x > 6 разность только уменьшается, поэтому других решений нет.

Математическая модель:
252 : x – 252 : (x + 1) = 6
Ответ:

На экскурсию надо заказать 6 больших автобусов.

Получаем два равенства: 1) xy = 252; 2) (x + 1)(y – 6) = 252.

Из первого равенства видно, что x и y — такие натуральные числа, произведение которых равно 252, причём y > 6.

Составим таблицу пар чисел, произведение которых равно 252:

Из таблицы видно, что второму равенству удовлетворяет только пара x = 6, y = 42.

На экскурсию надо заказать 6 больших автобусов.

Задача 5 Модель с цифрами числа (метод перебора)

Пример:

Задумано двузначное число, которое на 52 больше произведения своих цифр. Какое число задумано?

Пусть x — цифра десятков, y — цифра единиц. Тогда число равно 10x + y, а произведение цифр — xy.

По условию:

10x + y = xy + 52

Правая часть больше 52, значит, и число больше 52. Поэтому x ≥ 5 — проверяем значения x от 5 до 9.

При x = 5: 50 + y = 5y + 52 — левая часть меньше правой, невозможно.

При x = 6:

60 + y = 6y + 52 60 = 5y + 52 5y = 8

— для натурального y невозможно.

При x = 7:

70 + y = 7y + 52 70 = 6y + 52 6y = 18 y = 3

Число 73 подходит: 73 = 7 · 3 + 52.

При x = 8:

80 + y = 8y + 52 80 = 7y + 52 7y = 28 y = 4

Число 84 подходит: 84 = 8 · 4 + 52.

При x = 9:

90 + y = 9y + 52 90 = 8y + 52 8y = 38

— невозможно.

Значит, подходят числа 73 и 84.

Математическая модель:
10x + y = xy + 52
Ответ:

Задумано число 73 или 84.
